1 — The audio panel in the main window (track rows ①–⑬)
Default design — one coherent row anatomy Audio is a panel docked under the timeline (the transport speaker button toggles it). Row grammar: file + state badge · timeline placement · volume · the two JOB toggles — “Hear while working” (a preview mute: animate without being distracted by e.g. music) and “In exported video” (what ships: e.g. match the animation to a voice clip you don’t want in the export) · level meter · remove. The trash button always removes the row it sits on; “Add audio track” lives once at the end of the list.
The state badge, the two toggles, and the header counts all derive from the same two flags and can never disagree.

3 — What the export will do to the levels
Default design — read-only level strip No play button anywhere. The strip shows what the export will do to the levels while you work: a combined level meter for everything marked “In exported video”, live during playback, and a latching CLIP warning when that sum would pass the loudest possible level — exactly where the exported sound would distort.

Only tracks marked “In exported video” count here (2 of them). Reference, parked, not-set, and error rows contribute nothing.
Transport integration point The transport’s speaker button toggles the DOCKED panel (checked state = visible). The combined level meter rides along with ordinary playback — there is no special playback mode. The timeline’s own playback-window band keeps its reserved color; the audio panel never wears it.

Remove affordance — Option R1 (default in the rows above): always-visible trash button A trash icon with tooltip “Remove this track”. Unmistakably destructive — the bare × read as “close”. The row it sits on is the row that goes (R2 user review: the ×-delete trap).
Remove affordance — Option R2: trash on row hover Same icon and tooltip, revealed only on row hover so rows read quieter at rest. Risk: the affordance is undiscoverable until hover. OPEN — choose one.
Label vocabulary — DECIDED: “Hear while working” / “In exported video” Adopted from the fresh-eyes review: no decoding needed, and the words match the state badges. The shorter set (“Audible” / “In export”) was considered and rejected: it reads like jargon. “Start frame” / “End frame” with an explicit “fr” unit replace the cryptic “at”/“to”; tooltips answer the remaining questions (“end can’t come before start”, “in frames”, and unticking “In exported video” never mutes playback).

6 — Design notes: where each binding answer and R-fix lives
Q1 — export-mix level visibility (REVISED: audition dropped): §3 master strip — PASSIVE only, no play button: a MIX level meter (the SUM of In-export tracks’ contribution, live during preview playback) and a latching CLIP warning for the ±1.0 hard clamp (G1), captioned “What the export will do to the levels”. Export-only tracks are never hearable anywhere in the app (DECISION 2). Q2 — 4 meaningful combos: §2 truth table, four captioned rows (heard + exported / reference only / export only / parked) with badges derived from the two flags; §1 panel badges derive counts the same way (unconfigured counts toward nothing). Fixes R1: export-only is counted and mapped into the mixer. Toggle framing (DECISION 2): “Audible” = a preview mute (animate without being distracted by e.g. music); “In export” = what ships (e.g. match the animation to a voice clip you don’t want in the export). Q3 — docked/inline: §1 — the panel is a main-window dock below the timeline; the transport speaker button toggles it (checked pill), never a detached Qt::Window (old flow stopped all players on open — gone). §3 transport integration caption. Q4 — audio follows video: no divergent audio UI anywhere: export uses the per-range cut-together mix (R12 kept deliberately; Exporter.cpp:588-593) and nothing in the UI implies otherwise. Q5 — clamp + explicit “to end” (REVISED): §1 placement cells — “to” clamps ≥ “at” at the control while a number is entered (F36-style); an explicit “to end” toggle disables the end input, which reads “end of range” (rows 2 and 3 of §2 show it on). Users never see or type 0 — it is internal storage only, meaning “to end” everywhere in code. Replaces the 500 default (R11) and dissolves the clamp/sentinel tension (§7, C1 RESOLVED). Q6 — round-trip all tracks: §4 Config tab — save writes every row (unconfigured/parked/errored included), load restores all and marks invalid ones on their rows with a summary line. Fixes R2; R7 (Placeholder-as-flag) dies with the explicit empty-path state (§2 “unconfigured”); R14 defaults are now announced. Q7 — inline per-row errors: §2 error state — danger hairline (red row hexes), inline banner naming the file with Relocate/Remove, mirrored in the §4 load summary. Fixes R13’s silence. File-scope failures use the same inline grammar (§5 F1, DECIDED); C2’s overwrite confirmation keeps a small modal (the one remaining dialog). Q8 — engine features allowed: §3/§5 — per-row level meters + the passive MIX sum meter and latching CLIP warning (sanctioned engine addition: per-track levels or a sum hook from AudioMixer). The audition buffer and decode-progress additions went away with the audition (§7, C5 MOOT). Q9 — remove the clicked row: §1 rows ① = per-row × + footer Add; §2 add/remove flow diagram. Fixes R9 including the 2-track divergence; the dual-mode button and its invariant comment are gone (R5’s grid pressure too — the row is a CSS grid, not a 5-column QGridLayout). Q10 — timeline placement: §1 headers “Placement on timeline — at frame / to frame”, per-row mini span bar, duration readout = placed span (“200 fr · 0:08.3”); §2 playing caption states preview position = playhead − startFrame. Resolves R15 to the export/mixer reading. Cross-cutting R-fixes: R3 (objectName collision) — every control gets a unique id in the implementation spec; R4 (teardown/rebuild) — rows mutate in place (add/remove flow caption); R6 (scratch-dir icon coupling) — icons stay runtime-tinted, tint specified via CSS variables only; R8 (core→GUI layering) — .aemus parsing moves to a non-GUI module (the Config tab is only a view); R10 (mute inversion) — the export checkbox keeps “Export with audio” wording; one inversion at the request boundary, asserted in tests; the §4 facts row speaks mix language, never “mute”. Theme discipline: all hexes verbatim from TailwindPalette.h (accent rows at dark cols 7/4 per Colors.h kAccent/kAccentBright). Audio chrome uses only neutral tokens — accent is untouched (reserved for playhead/selection/marquee); the focus ring is the only accentBright borrow. kWindowBand/kWindowEdge appear solely as the timeline placement-span/playhead visuals (its reserved playback-window meaning). Volume = ToolSlider look (circular head on thin track). Status hues (green/amber/orange/red rows) are reserved for meters and errors. 7 — Conflicts: closed at revision (C1/C4 RESOLVED · C2/C3/C5 MOOT)
C1 — RESOLVED (was: Q5 clamp × sentinel tension): the explicit “to end” toggle (DECISION 3) dissolves it — “to end” is exempt from the end≥start clamp (a numeric end is still clamped at the control), and end=0 means “to end” EVERYWHERE in code: the old empty-window reading of getValidAudioStreams (“non-empty window”, AudioPlaybackWidget.h:103) and syncTracks’ half-open [startFrame, endFrame) dies. Users never see 0. C2 — MOOT (was: Q1 × export surfaces): the audition is removed (DECISION 1), so there is no mix-preview whose scope could clash with the export dialog’s “Export with audio” or containerCarriesAudio. The passive MIX meter reads In-export track levels only and claims nothing about the pending dialog. C3 — MOOT (was: Q1 × Q4 range ambiguity): the audition is removed; no UI element renders or plays a mix, so the question of which range (timeline / selection / export range) it would use no longer arises. Export keeps the per-range cut-together concat (R12). C4 — RESOLVED (was: Q7 scope gap): file-scope failures (JSON parse error, deserialize failure) use the inline danger banner grammar (§5 F1, DECIDED); C2’s overwrite confirmation keeps a small modal — the one remaining dialog class (§5, DECIDED). C5 — MOOT (was: Q8 decode-progress creep): the “Mixing… N tracks decoded” state was part of the audition and is gone. The passive MIX meter + latching CLIP warning remain as the sanctioned Q8 engine addition (per-track levels or a sum hook; mix() stays one-shot).
